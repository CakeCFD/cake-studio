4. WHAT THIS INSTALLER DOES

To install CakeStudio, this setup program will, with your permission:

  a) If needed, enable the Windows Subsystem for Linux (WSL2) and install Ubuntu 24.04. This requires administrator approval and a restart. WSL is provided by Microsoft and Ubuntu by Canonical under their own terms.
  b) Add the OpenFOAM package repository (dl.openfoam.com) to Ubuntu and install OpenFOAM v2412 and the libraries CakeStudio needs from the Ubuntu and OpenFOAM repositories.
  c) Download CakeStudio from its GitHub releases page and install it inside Ubuntu, in your home folder.
  d) Optionally install the TENO scheme library into your OpenFOAM user library folder.
  e) Install a small Windows launcher, create the shortcuts you select, and register CakeStudio under "Installed apps" so it can be uninstalled.

The installation needs an internet connection and about 2 GB of disk space.
